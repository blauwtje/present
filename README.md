# Cadeau

Cadeau-ideeën voor één persoon. Vul in wat je leuk vindt en wat je al hebt, geef elk idee een score van 1 tot 5, en de volgende ideeën passen beter.

- App: Vite, React, TypeScript. Alles draait in de browser; profiel en scores staan in IndexedDB.
- Catalogus: gebouwd door de workflow `Catalog` en bewaard in release `catalog-v1`.
- Deploy: workflow `Deploy` bij elke push naar `main`.

```
npm ci
npm run dev        # lokaal; zet een catalogus in public/catalog/
npm test
```

Plan: `docs/specs/cadeau-app.md`. Keuzes: `DECISIONS.md`.
